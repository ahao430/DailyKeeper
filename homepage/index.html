deploy.sh 
$ git clone https://github.com/ahao430/DailyKeeper.git
$ cd DailyKeeper && cp deploy/.env.example deploy/.env
$ docker compose -f deploy/docker-compose.yml up -d --build

执行线

三条执行线，同一个任务引擎

每次执行都会自动路由到合适的运行端。

HTTP 执行线

API 任务由服务器 Worker 执行，经插件 HTTP 客户端调用。

  • 数据库队列 + 乐观锁认领
  • 按业务日期幂等去重
  • 超时控制 + 退避重试
浏览器执行线

Playwright + Chromium。

  • 按账号持久化登录态 —— 登录一次，长期复用
  • 真实浏览器登录，完成 M-Team 每日保活
  • 未部署浏览器 Worker 时自动进入 NEEDS_ACTION 守卫
Agent 执行线

dk-agent 拉取式协议。

  • 心跳 / 认领 / 拉取上下文 / 回传结果
  • 插件运行在用户自己的环境里
  • 一次性令牌，可轮换、可撤销
快速开始

四条命令完成部署

一份 Docker Compose 文件，四个协同进程。

1

部署

一份 compose 文件拉起四个进程：api / scheduler / worker / browser-worker。

2

配置

添加平台实例与账号；凭据 AES-GCM 加密落盘。

3

自动化

创建每日定时任务，立即执行一次，查看执行记录与资源趋势。

git clone https://github.com/ahao430/DailyKeeper.git
cd DailyKeeper
cp deploy/.env.example deploy/.env   # 务必修改 SECRET_KEY！
docker compose -f deploy/docker-compose.yml up -d --build
# 控制台：http://localhost:8080 · API 文档：http://localhost:8000/docs
